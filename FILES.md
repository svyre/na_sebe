# Каждый файл архива

В полном проекте 136 файлов. Ниже перечислены все, включая скрытые настройки. В ZIP для запуска входят 14 собранных файлов, README.md, LICENSES.txt и SECURITY_STATUS.md; исходники публикуются отдельно в GitHub. `node_modules` в ZIP нет: эта папка появляется локально после `npm ci` и содержит установленные сторонние зависимости.

Для обычной игры достаточно открыть `index.html`. Для редактирования используются исходники в `source`. Файлы с расширением `.tsx` — компоненты React, `.ts` — типы и логика, `.css` — оформление, `.mjs` — скрипты Node.js. Изображения и шрифт — двоичные ресурсы.

## Как читать код по порядку

1. `source/entry.tsx` → `App.tsx`: запуск, навигация и сохранённая партия.
2. `Game.tsx` → панели: как выбор игрока становится планом месяца.
3. `lib/game/types.ts`, `config.ts`, `planning.ts`, `settlement.ts`: данные, ограничения и расчёт.
4. `month-review.ts`, `History.tsx`, `Results.tsx`: объяснение результатов.
5. `scripts/check-*.mjs`: примеры ожидаемого поведения и граничных случаев.

Пути компонентов в этом списке относятся к `source/app/ui/`. Изменения в исходниках проверяются командами `npm test` и `npm run format:check`, а затем попадают в готовую страницу после `npm run build`.
