# Размер и оптимизация веб-сборки

Готовая игра с историей и обучением занимает 1 965 435 байт без ZIP-сжатия: JavaScript — 691 616 байт, CSS — 186 664 байта. Размеры текущей версии выводит команда `npm run build`. Изображения, шрифт и значок вкладки лежат отдельными локальными файлами. В прежней слитной версии HTML занимал 2 137 263 байта и включал двоичные данные base64.

Двоичные ресурсы не изменены: персонажи остаются в WebP без потерь, Onest — в WOFF2 с прежними глифами и метриками. Файлы имеют отдельные пути и могут кэшироваться браузером. Это изменение способа доставки, а не обещание одинаковой скорости на любом телефоне.

Сохранены переиспользуемые Intl.NumberFormat, мемоизация рисунков и остановка анимаций вне экрана и в скрытой вкладке. Сборка удаляет неиспользуемые CSS-селекторы. В версии с хардкором добавлены календарные ограничения и развитие; код и ресурсы по-прежнему публикуются отдельными файлами.

Для повторного замера функций модели используй `npm run benchmark` в `source`. Проверка сборки ограничивает общий размер готовых файлов 2,5 МБ и проверяет отсутствие встроенных скриптов и двоичных данных base64. Настольный Microsoft Defender здесь не запускался; сведения о проверке безопасности находятся в [SECURITY_STATUS.md](SECURITY_STATUS.md).

В версии на 1–3 года добавлены 72 текстовые ситуации и расчёт активов. Графика и шрифты не дублируются. Будущие годы подбираются по одному месяцу; полный список ситуаций не пересоздаётся при каждом изменении плана. Точные размеры выводит сборка.

36 глав, реплики и обучение не добавляют изображений или внешних запросов. Глава вычисляется при изменении данных партии, а не при каждом движении ползунка плана. Записи разговоров сохраняются по одному снимку на завершённый месяц. В подготовленном CSS сохраняются только используемые состояния, включая динамическую подсветку и цвета знакомых.
