# на себе

Одиночная игра о первом годе самостоятельной жизни. В этом архиве — оптимизированная HTML-версия и читаемые исходники React/TypeScript.

## Запустить игру

Распакуй ZIP и открой `index.html` в современном браузере. Node.js для этого не нужен. Код, стили, шрифт и изображения встроены в HTML, поэтому после скачивания игра работает без интернета.

Для публикации на GitHub Pages загрузи в корень репозитория `index.html`, `.nojekyll` и `LICENSES.txt`. Затем выбери нужную ветку и корневую папку в Settings → Pages. Для этой версии сервер и база данных не нужны.

## Разобраться в проекте

- [FILES.md](FILES.md) — объяснение **каждого файла** архива: зачем он нужен, что содержит и когда его менять.
- [ARCHITECTURE.md](ARCHITECTURE.md) — путь данных от выбора игрока до отчёта и сохранения, а также порядок расчётов месяца.
- [PERFORMANCE.md](PERFORMANCE.md) — что ускорено, измерения до и после, методика проверки.
- [CODE_REVIEW.md](CODE_REVIEW.md) — повторная проверка читаемости, изменения и изученные источники.
- [source/DESIGN.md](source/DESIGN.md) — устройство оформления, сцены, адаптивность и анимации.
- [LICENSES.txt](LICENSES.txt) — уведомления о сторонних библиотеках, шрифте и графике.

Для чтения начни с `source/entry.tsx`, затем открой `App.tsx` и `Game.tsx` в `source/app/ui/`. Правила расчёта находятся в `source/lib/game/`.

## Разрабатывать

Установи Node.js 22 или новее; при подготовке архива использован Node.js 24. Открой терминал в папке `source`:

```sh
npm ci
npm test
npm run format:check
npm run build
```

`npm ci` устанавливает точные версии из `package-lock.json`. После сборки готовый `index.html` появится на уровень выше папки `source`.

Для автоматического форматирования:

```sh
npm run format
```

Редактируй файлы в `source`, затем пересобирай игру. `index.html` — результат сборки: его JavaScript уплотняется автоматически для загрузки, а понятные исходники остаются в `source`.

## Что изменено при очистке

Данные ситуаций отделены от формул, а большой игровой экран разделён на самостоятельные панели. Сохранение вынесено из корневого компонента. Удалены недоступные в одиночной версии ветки командной игры, неиспользуемые импорты и переменные. Логотип банка хранится одним изображением вместо длинных повторяющихся строк в компонентах. Стили разложены по назначению с сохранением порядка каскада. Названия основных переменных раскрывают смысл, форматирование проверяется общей командой.

Правила, внешний вид и формат сохранений сохранены. У сохранений остался прежний ключ `na-svoih-solo-v1`; старые завершённые месяцы не пересчитываются. Доступ к прогрессу зависит от того же адреса страницы и браузера: между разными адресами или устройствами он автоматически не переносится.

## Проверка этой версии

- 60 проверок модели, ситуаций, месячных рекомендаций, мебели, сохранений и сборки.
- Сравнение со старой версией: 120 лет, 1 440 закрытых месяцев, 1 440 прогнозов и 540 выборов на трёх сложностях дали одинаковые результаты.
- В браузере пройдены полный год со случайными историями и год с покупкой всех улучшений, проверены смена персонажа, старые сохранения, CSV и ширины 320–1440 пикселей.
- Проверены главная, комната, ситуации, план и банк на ширинах 390 и 1440 пикселей. Геометрия сохранена; различия декодирования WebP в Chromium ограничились одним уровнем цветового канала из 255.
- Проверены движение, пользовательская пауза, системное уменьшение движения и остановка анимаций вне экрана и в скрытой вкладке.

Для повторной проверки после правок используй `npm test`, `npm run format:check` и `npm run build`.

## Оптимизация

Размер готового HTML уменьшен с 3,44 до 2,14 МБ. Персонажи разделены на шесть кадров WebP без потерь, шрифт переведён в WOFF2 с сохранением всех знаков и начертаний. При сборке удаляются неиспользуемые селекторы CSS; исходные стили остаются читаемыми.

Форматирование чисел переиспользует готовые `Intl.NumberFormat`. Неизменившиеся SVG комнаты, персонажей и предметов не пересоздаются при открытии служебных панелей. Вне экрана и в скрытой вкладке анимация приостанавливается с сохранением текущего кадра; выбор пользовательской паузы не меняется.

Для локального замера модели выполни `npm run benchmark` в `source`. Подробные результаты и ограничения измерений приведены в [PERFORMANCE.md](PERFORMANCE.md).

Настройки дополнительных сцен собраны по идентификаторам, а рекомендации месяца читаются как последовательность условий. Комментарии о причинах важных решений сохранены; подробное назначение файлов по-прежнему описано в `FILES.md`.

Оптимизации и формат сохранений сохранены. Правила не менялись: дополнительно сравнены результаты месяцев, сводки и визуальные данные всех ситуаций. Обоснование правок и ссылки на источники — в [CODE_REVIEW.md](CODE_REVIEW.md).
