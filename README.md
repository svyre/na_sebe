# на себе

Готовая одиночная версия для GitHub Pages: новый логотип, три уровня сложности, 12 месяцев, банк, история, отчёт и сравнение решений.

## Открыть на компьютере

Распакуйте архив и откройте index.html двойным щелчком в современном браузере. Устанавливать Node.js и запускать команды не нужно. Все игровые скрипты, стили и изображения встроены в index.html. Шрифт и иллюстрации тоже встроены: после скачивания игра работает без интернета.

## Разместить на GitHub Pages

1. Создайте на GitHub публичный репозиторий na-sebe. На бесплатном тарифе Pages доступен для публичных репозиториев.
2. Нажмите Add file → Upload files. Загрузите index.html и .nojekyll из этого архива, а также LICENSES.txt. ZIP загружать не надо. Файл index.html должен лежать сразу в корне репозитория, а не внутри дополнительной папки.
3. Сохраните файлы в ветку main.
4. Откройте Settings → Pages.
5. В Source выберите Deploy from a branch.
6. Выберите Branch: main и Folder: / (root), затем Save.
7. Дождитесь успешного завершения публикации во вкладке Actions. Ссылка на сайт появится в Settings → Pages.

Никакие команды сборки, секреты или база данных для этой версии не нужны. Она подходит для пользовательского сайта и для сайта проекта во вложенной папке.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что работает

- Три уровня: Первый шаг / Баланс / Вызов.
- Все три цели, набор из 60 ситуаций и 12 месяцев со случайными 1–3 историями в каждом.
- Планирование денег, времени, учёбы и личного ресурса.
- Накопительный счёт, учебный фонд, сравнение кредитов.
- История решений, оценка стратегии, скачивание CSV-отчёта.
- Сравнение альтернативного решения в рамках выбранной сложности.
- Сохранение прогресса в текущем браузере на текущем устройстве.

В этой статической версии только одиночная игра. Командные комнаты и кабинет ведущего доступны в основном серверном приложении: https://na-svoih-finlab.serebrovv09.chatgpt.site

Прогресс не синхронизируется между устройствами. Очистка данных сайта и приватный режим могут помешать сохранению. Все суммы, ставки и договоры — игровые.

## Исходники для дальнейшей разработки

Папка source содержит React/TypeScript-код именно этой статической версии и скрипт повторной сборки. Для обычного запуска игры и размещения на Pages эта папка не нужна.

Для редактирования установите Node.js, откройте терминал в папке source и выполните:

```sh
npm install
npm run check
npm run test:game
npm run build
```

Новый index.html появится уровнем выше — рядом с этим README. Публикуйте его вместе с .nojekyll и LICENSES.txt.

Проверено: типы TypeScript, неизменность игровой модели относительно опубликованной версии, полный год на уровне Вызов, восстановление после перезагрузки, альтернативное решение, мобильный экран и перевод в накопления. Проверка выполнена на локальном статическом сервере по вложенному пути /na-sebe/.


## Обновлённый дизайн

В этой версии переработаны главная страница, навигация и оформление игровых экранов. На главной можно распределить пробный бюджет ползунком и сравнить стартовые условия уровней. Выбранная сложность передаётся в окно начала игры. Пробный ползунок не меняет сохранённую игру.

Шрифт Onest встроен в HTML: внешний запрос к Google Fonts больше не нужен. Игра работает без сервера и подключения к интернету. Исходники оформления находятся в source/redesign.css, описание решений и исследованных референсов — в source/DESIGN.md, лицензия шрифта — в LICENSES.txt и source/assets/Onest-OFL.txt.

Проверено после редизайна: TypeScript, 15 тестов игровой модели; браузерные проверки на ширинах 320, 390, 768, 1024 и 1440 px, ползунок с клавиатуры, запуск с выбранной сложностью, завершение месяца на компьютере и телефоне, восстановление прогресса, поиск в словаре и навигация. Публикация на GitHub Pages не выполнялась.

## Игровые сцены и Газпромбанк

Все 60 ситуаций из общего набора представлены иллюстрированными сценами с персонажем, репликой и предметами. Выбирать можно нажатием на предмет, кнопкой в сцене или иллюстрированной карточкой. Радиокнопки поддерживают клавиатуру; исходные документы с условиями доступны перед ходом. Выбор меняет план и прогноз бюджета, а окончательные последствия раскрываются после завершения месяца.

В игре добавлены вход в учебный банк, карта с логотипом Газпромбанка, банковское приложение в сцене безопасности и фирменное оформление месячного разбора. Это учебная модель: реальные банковские счета, переводы, продукты и ставки не подключены. Использован существующий логотип из исходного проекта.

Сводка месяца объясняет, что получилось, что стоит пересмотреть и какой следующий шаг полезен. Она учитывает фактические изменения денег, долгов, учёбы, сил и безопасности. Использование резерва и дорогая покупка сами по себе не считаются ошибками. Новые долги и отложенные платежи учитываются отдельно от текущих расходов.

Дополнительная проверка разбора из папки source:

```sh
node scripts/check-review.mjs
```

Сцены: source/app/ui/StoryScene.tsx. Учебная карта: source/app/ui/BankIdentity.tsx. Правила обратной связи: source/lib/month-review.ts. Оформление: source/story.css. Сцены рисуются средствами SVG; новые персонажи используют встроенный прозрачный PNG со спрайтами. Все изображения, логотипы и шрифт встроены в единый HTML.


## Случайные ситуации и новые персонажи

Перед стартом можно выбрать мальчика или девочку. Персонажи перерисованы по предоставленным пользователем референсам: мультяшные пропорции, коричневые волосы, синяя одежда, тёмные брюки и светлые кеды. У каждого есть спокойная, радостная и задумчивая поза. Выбранный персонаж появляется в профиле и во всех сценах. Смена внешности сохраняет прогресс и текущий план.

В каждой новой игре создаётся случайное расписание на 12 месяцев. Каждый месяц содержит от 1 до 3 ситуаций из общего набора 60; распределение количества равновероятное. Истории могут появляться в любом месяце и не повторяются в течение года. За одно прохождение доступно от 12 до 36 историй. Каждая история предлагает три действия с собственными денежными, временными и отложенными последствиями.

Расписание записывается в сохранение сразу при старте. Перезагрузка страницы не меняет количество или набор ситуаций. У старого сохранения сохраняются завершённые месяцы, деньги и отчёты; для будущих месяцев создаётся случайное расписание с исключением уже пройденных историй.

Все ситуации месяца используют общий бюджет и запас времени. Для закрытия месяца требуется выбрать действие в каждой выпавшей истории. Сводка, история и CSV содержат фактически выпавшие ситуации. Сравнение альтернатив меняет решение в первой ситуации выбранного месяца и сохраняет остальные ситуации и решения.

24 новые темы: повреждённая посылка, подмена QR-кода, кешбэк и лишняя покупка, потеря карты, помощь другу, забытый пропуск, стол с рук, прачечная, бюджет команды, дорога на практику, учебный грант, волонтёрство, срочная печать, мобильный тариф, резервная копия, присмотр за собакой, билет у незнакомца, ложный банковский курьер, комиссия площадки, найденный кошелёк, лицензия программы, общий сбор, поездка в дождь и практическая кулинарная мастерская.

Карта и оформление Газпромбанка используются в учебной симуляции. Реальные банковские продукты и операции не подключены.

Проверки из папки source:

```sh
npm run check
npm run test:game
node scripts/check-review.mjs
npm run test:stories
npm run build
```


## Живые персонажи и 16 локаций

У каждой из 60 историй задано подходящее место: комната, общая кухня, университет, библиотека, кафе, магазин, учебное пространство Газпромбанка, коворкинг, станция, парк, набережная, мастерская, прачечная, пункт выдачи, городское событие или улица. Локации отличаются архитектурой, мебелью и предметами. Погода и зимнее оформление зависят от контекста и месяца.

Персонаж плавно появляется в сцене, слегка двигается в ожидании, радуется выбору с положительным влиянием на ресурс или задумывается над другими действиями. При низком ресурсе используется задумчивая поза. Реакция сопровождает выбор и не раскрывает скрытых финансовых последствий. Нажатие на предмет повторно воспроизводит реакцию. Движения не занимают игровое время и не меняют показатели.

В отдельных локациях есть движение окружения: пар в кафе, поезд на станции, вода на набережной, барабан стиральной машины, облака, снег и дождь. Оформление Газпромбанка использует существующий логотип проекта.

Кнопка паузы рядом с сердечками отключает анимации. Настройка сохраняется в этом браузере отдельно от игрового прогресса и действует при переходе между ситуациями. Если на устройстве включено уменьшение движения, анимации автоматически отключаются; выборы и остальные функции продолжают работать.
